NASA POWER DAILY point data, 1981-01-01 to 2025-12-31 (16,436 days per file). Lat/lon in file name.
Columns: date, T2M (mean air temp degC), T2M_MAX (daily max degC), T2M_MIN (daily min / night degC),
         PRECTOTCORR (rain mm/day), RH2M (relative humidity %)
Use for: heatwave days (T2M_MAX > 40), warm nights (T2M_MIN), extreme rain days (> 50 mm), dry spells, heat index (T2M + RH2M).
Note: Amaravati and Vijayawada share the same NASA grid cell, so only amaravati is included.
